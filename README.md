# Metroid Dread Randomizer Tracker

A standalone desktop app for Windows and Linux that provides automatic resource tracking, as well as manual hint tracking, for Metroid Dread games randomized with [Randovania](https://github.com/randovania/randovania). The tracker can connect to physical Switch consoles as well as emulators supported by Randovania, provided that the target is on the same LAN as the computer running the tracker (and/or the same computer, in the case of emulators). Automatic tracking requires that the "Enable automatic item tracker" option be enabled in the Randovania Cosmetic Options when exporting the game.
